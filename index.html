Hey Whisper Flatpak Repository

This page hosts a self-updating Flatpak repository for Hey Whisper.

flatpak remote-add --user --no-gpg-verify hey-whisper https://rmonk.github.io/hey-whisper/repo
flatpak install --user hey-whisper org.heywhisper.HeyWhisper

This repo is populated automatically by CI on each tagged release. If you're seeing this placeholder page, no release has published to it yet.
